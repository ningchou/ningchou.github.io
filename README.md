# Ning｜AI 協作作品集

Ning 的個人作品集網站：四個實際在用的工具，以及兩套和 AI 協作的工作方法。

- 網址：https://ningchou.github.io/
- 內容：AI 新聞收件匣、臨床資料工具、LotCompass、Local-Backtest；流程與驗收 Skill、AI 協作工作區。

## 結構

| 檔案 | 用途 |
| :--- | :--- |
| `index.html` | 首頁：介紹、作品卡、關於我 |
| `inbox.html`、`clinical.html`、`lotcompass.html`、`local-backtest.html`、`skills.html`、`workspace.html` | 六個作品頁 |
| `style.css`、`theme.js` | 共用樣式與深淺色切換 |
| `assets/` | 臨床資料工具、Local-Backtest 截圖，LotCompass 報告圖與原始 HTML 報告（皆為合成資料；舊格式 Excel 為依原欄位重建的假資料） |

純 HTML／CSS，不需要建置。改內容時一併更新各頁頁尾的「最後更新」日期。

- 網站與工具的主要程式由 AI Agent 協助實作；需求、規則、驗收與最後決定由 Ning 負責。
- 工具截圖皆使用合成資料，未連接正式系統。
